Concepto de Metodología

El Modelo Sistémico de Calidad (MOSCA) es una Metodología sistémica (9 letras).

Enfoque Sistémico

Propone evaluar la calidad analizando la interacción dinámica entre todos los componentes del software como un sistema íntegro.

M.O.S.C.A.

Mantenibilidad, Operabilidad, Seguridad, Confiabilidad, Adaptabilidad.

Arquitectura Técnica

Submodelos de evaluación integral (11 letras).

Producto

Enfoque en el software terminado y funcional (8 letras).

Proceso

Focalizado en las metodologías de construcción (7 letras).

Humana

Mide la competencia y el rol del factor humano en la calidad.

Nivel 1: Categorías

El modelo se desglosa en 11 Categorías críticas de control (10 letras):

06

De Producto: Funcionalidad, Fiabilidad, Usabilidad, Eficiencia, Mantenibilidad, Portabilidad.

05

De Proceso: Ingeniería, Gestión, Soporte, Cliente-Proveedor, Organizacional.

Producto: Garantía y Valor

Funcionalidad

Capacidad para satisfacer necesidades técnicas explícitas.

Seguridad

Nivel de protección ante vulnerabilidades (9 letras).

Fiabilidad

Robustez del sistema ante fallos inesperados.

Experiencia de Usuario

Usabilidad (10 letras)

Facilidad de aprendizaje y manejo para el usuario final.

Mantenibilidad (14 letras)

Esfuerzo necesario para implementar cambios y mejoras continuas.

Resiliencia de Entorno

Adaptabilidad (13 letras)

Capacidad del sistema para evolucionar ante nuevos requisitos.

Portabilidad

Facilidad para migrar el software entre plataformas distintas.
